# 飞书机器人底部快捷入口

飞书的消息卡片按钮只能显示在聊天消息里，不能由发送消息的代码固定到输入框上方。想要接近 Telegram 底部键盘的效果，需要在飞书开放平台为机器人配置「自定义菜单」。飞书客户端决定菜单的实际外观和位置，不能保证与 Telegram 的多行键盘完全一样。该菜单主要用于机器人单聊。

在飞书开放平台打开当前应用的「机器人」→「自定义菜单」，启用后添加「发送文字消息」类型的菜单项：

| 菜单名称 | 发送文字 |
| --- | --- |
| 提交 RAG | `/rag` |
| 帮助 | `/help` |
| 插入任务 | `/insert` |
| 替换任务 | `/replace` |
| 取消任务 | `/cancel` |
| 清理记忆 | `/clean` |

前两项尤其适合常用入口；若平台限制菜单项数量，可优先保留「提交 RAG」「插入任务」「替换任务」「取消任务」，并把其余操作放到「更多」子菜单或通过 `/menu` 调出消息内卡片。不要选择「推送事件」动作：当前接收链路按文字命令处理菜单点击，没有订阅菜单点击事件。

保存菜单、按飞书要求发布应用版本后，在机器人单聊检查客户端是否显示。若开放平台提供「悬浮菜单」展示方式，可以选择它；不同版本的移动端、桌面端布局可能不同。菜单项不会由本仓库代码自动创建；只更新本地代码并重启机器人，不会在飞书客户端凭空出现底部按钮。

本地配合逻辑：`/rag` 会按当前发送者开启一次性上传模式；`/insert` 和 `/replace` 在没有附带内容时等待下一条文字；`/menu` 显示消息内卡片作为备用入口。普通任务完成后不再自动发送快捷操作气泡。若按需卡片发送被平台拒绝，服务端日志会记录错误码与提示，并回退到文字命令。
