# 2026-09-15 public repository release

This release consolidates the PersonalOps runtime, structured planning and review protocols,
local retrieval, Feishu ingress, AppWorld evaluation tooling, and reproducible local classifier
setup into one public repository.

Privacy boundary: the release excludes `.env`, API keys, personal conversations, raw AppWorld
tasks, simulated account data, Phoenix traces, execution archives, local model weights, and
runtime databases. Public demonstrations use synthetic content; benchmark material is aggregate.
