# 1688 深度找：本地工具接入

这是[阿里云云市场“1688深度找”商品](https://market.aliyun.com/detail/cmapi00073492)的 API，不使用百炼 `DASHSCOPE_API_KEY`。项目调用 `POST https://cbu.market.alicloudapi.com/deepsearch`，使用云市场 `Authorization: APPCODE ...` 鉴权。当前账号的 AppCode 和已验证可工作的 `app_id` 放在 Git 忽略的项目根目录 `.env.1688.local`，分别为 `ALIYUN_MARKET_1688_APPCODE` 和 `ALIYUN_MARKET_1688_APP_ID`。不要提交该文件。连接设置 `trust_env=False`，不继承本机代理配置。

项目启动时，只有两项配置存在才把 `search_1688_products` 加入真实工具池，`ECOMMERCE_1688` 工具组才出现在能力目录。云市场 REST API 没有无费用的健康检查；配置齐全不保证服务以后始终可用，调用失败时工具会返回明确错误，服务到期、配额和密钥状态也可能改变。更新配置后重启应用，目录会重新判断。

## 数据和模型可见字段

上游单次最终 ANALYZE 阶段返回约 10 条商品；中途 RANK 阶段曾返回 11～30 条候选，但只有商品 ID 和非结构化文本，不作为已核对的价格结果。要得到 20～30 条，工具最多用三个同类、不同表达的查询，按真实商品链接去重，不保证一定满额。

工具只向模型返回：商品标题、1688 商品链接、起订量、起订量对应的首档单价、最多四档阶梯价、供应商名称、查询时间，以及原始条数、过滤数、重复数和实际保留数。不会转交中间分析、原始长文、追踪字段、商品图片或完整供应商元数据。自动过滤邮费/运费/补差价/定金链接、无效价格、无效 URL、重复链接；默认过滤起订量超过 10 件的货源，批量采购任务可以调高该上限。

这是 **1688 B2B 货源报价**，并非淘宝零售价或市场均价。首档价格与商品页可能变动；低价阶梯通常要求更多采购件数。显卡等高价商品尤其应核对型号、成色、起订量与卖家，不得用异常低价推断消费者能按该价买到正品。

## 2026-09-18 实测

当前 AppCode 的 HTTPS 直连请求返回 HTTP 200、SSE 完成事件及结构化商品。女式连衣裙的三次相关查询共得 30 条上游最终商品，经基础清理及去重为 25 条；其中一条起订量 200 件，按默认起订量不超过 10 件的规则，保留 24 条。它们的首档单价在 19.79～88 元之间，样本中位数 45.35 元；这仅描述本次 1688 货源样本，不能代表普遍零售价。一次明确要求“返回30条并排除邮费”的上游查询仍只返回 10 条，其中 7 条为邮费/补差相关结果；因此过滤在本地完成，不把这些排除词发送给上游。

原始探测结果和归一化结果留在 Git 忽略的 `.agent/market-1688-probes/`，不进入模型上下文或仓库提交。接入与 AppCode 规则见[云市场商品页](https://market.aliyun.com/detail/cmapi00073492)和[阿里云云市场 API 使用说明](https://help.aliyun.com/zh/marketplace/user-guide/use-api-commodities)。
