# 从研究问题到原文证据

将问题转成核心概念、方法名、比较对象及时间范围；保留英文术语，中文名可帮助找到别名。知道题名/作者时先精确检索，未知时先用综述定位候选，再回原始研究。

优先出版社或会议页面、作者/机构公开稿、arxiv.org 等原文。核对作者、日期与版本，预印本不等于已评审。聚合站和博客用于发现链接，不能替原文证明方法或成绩。

先读摘要判断是否相关，再按问题读方法、实验、结果和限制，不机械下载全部参考文献。核对数据集、样本、基线、评价指标和计算预算；跨不同设置的数值不能直接排名。论文声称与独立复现分别说明。

付费墙或连接故障时用精确题名和作者换查会议论文集、作者/机构公开稿，并核对版本。实测：Attention Is All You Need 的 arXiv摘要与HTML均连接重置；换搜索结果中的NeurIPS论文集页，成功读到作者、2017会议身份、摘要与Paper PDF链接。下一步按问题读取论文对应章节，而不是继续刷新arXiv；当前摘要只支持其中明确陈述，不代表已读实验页。

结论保留论文身份、原文位置、支持的具体命题与未解决问题。只为关键证据缺口继续查找，不把多个转述当独立研究。
