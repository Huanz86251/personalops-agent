# 商品与店铺报价

## 先确定同一件商品

提取平台、店铺/商品链接、型号、容量/尺寸/颜色、数量、套装、新旧与地区版本。给定链接时先核对卖家和商品，不用另店同名商品替代，也不从搜索标题的“官方”二字认定店铺身份。

用“品牌 型号 规格 店铺/平台 价格”检索；已知平台文本页无正文时不把同一路径作为必经步骤。先判断用户要指定店现价，还是可接受跨店行情：前者保持卖家约束，后者可直接查其他公开商家。无结果先撤非核心限制，不猜商品ID。

## 拆开报价

每条报价绑定实际规格/SKU与卖家。低价可能对应配件、另一容量、订金或不同套装；核对数量、货币、运费、税费、现货/预售及优惠时间与门槛。不同口径不统一标成“最低价”。

只有条件明确且可核算时计算条件总价，说明条件；未知的新客/会员/地区/支付优惠资格和结算运费不能当已满足。区分公开标价、满足条件的计算价、页面实际展示结算价和成交记录；本流程不会购买，不能声称“已经这个价买到”。

## 读取与停止

真实浏览器可正常查看公开商品与影响报价的规格，不把查看变成加购、领券、锁库存、下单或付款。登录/验证码/强制App阻断不绕过，不为询价擅自登录。可请求用户提供明确规格或所需页面截图，标记店价未核实。

## 换来源，不偷换价格含义

平台不可读且允许跨店时，先改搜“精确型号 苏宁/其他公开商家 价格”，或品牌中国区在线商店的购买页，争取直接取得商家标价；不要先降级成参考行情。搜索命中的正规移动商品页也可正常浏览，同一平台不同入口的可读性不能一概而论。商品页身份、规格、标价、配送条件足够后停止扩搜。什么值得买用于带日期和条件的优惠线索，中关村在线用于型号/参考价与商家链接；二者不能默认替代店价。论坛成交帖只证明作者描述的那次交易；不向来历不明的“免登录镜像”提供账号。

实测换路（2026-09-06）：M650淘宝列表浏览器验证码，京东商品链接重定向403频控页；改搜“罗技 M650 京东 苏宁 售价”，打开命中的苏宁移动商品页 `https://m.suning.com/product/0000000000/12445857005.html`，项目浏览器实际读到M650-M白色910-006392、1件、¥290.81，默认配送山东青岛市南区、现货、满98元免基础运费，且写明供应商发货。供应商名称未展示，不能认定罗技旗舰店；15元支付券未核资格不减价，默认配送地不是用户地址，最终运费/结算未核实。这是该苏宁商品页公开标价，不是淘宝店价或全网最低价。

另一可用入口：Apple中国大陆购买页 `https://www.apple.com.cn/shop/buy-airpods/airpods-4`，浏览器定位“选择你的机型”一组，读到普通版RMB999、主动降噪版RMB1,399；按机型绑定价格，不能把月供RMB59或摘要混排当整机价。以上仅是已测试入口，不保证所有商品长期可达。此前ZOL269元仅参考报价、什么值得买194元为2023年过期优惠，不能拿来覆盖新商品页标价。

按“店铺/链接、精确规格、价格口径、优惠/运费条件、时点、缺口”比较少量候选。未确认价格留空，不能用厂商建议价、别店价或缓存填补。覆盖指定店铺/规格即结束；没有新路径不循环重试，不联系卖家或发送消息。
