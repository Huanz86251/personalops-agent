# 路线与交通

## 补齐改变路线的条件

核对起点、终点精确分店/入口、出发或到达日期时刻、交通方式和用户提出的无障碍/少步行限制。“我附近”不授权猜定位，缺关键起点要问，不把默认城市当用户城市。

## 区分静态指引与实时方案

地址/附近站点可先读运营方到访页。线路和首末班优先交通运营者具体站点/时刻表，核对方向、终点、日期与临时调整；第三方摘要只作线索。场馆写某站某出口不证明出口实时可用，也不提供用户全程用时。

门到门路线、路况只用实际可用的浏览器/地图能力，观察输入、选中实体及返回方案。缺能力时可以提供有来源的静态换乘信息并说明限制，不拼接站点距离伪造精确耗时。

## 按所需路线换路

地图文本壳先判断是否值得用真实浏览器渲染；若明确登录/安全验证阻断，停止该路径，改查能回答同一交通方式的公开来源。地铁可用具名站点/线路查询服务，公交查运营者线路与方向，场馆末段步行查到访入口。替代网站必须覆盖用户的城市和交通方式，不能把别城同名站、附近站点或直线距离拼成完整路线。

实测：高德地点页文本只有图片编码，浏览器显示地点获取失败及登录界面；百度提交莱西路线后出现安全验证。另以“虹桥火车站→上海科技馆站”为独立地铁样例，转ExploreShanghai：搜索并选中起站→路线查询→搜索并选中终站，得到2号线15站、估算47分钟/5元。此方法成功取得第三方站到站方案，不证明莱西路线已解出；更不包含场馆步行、候车或实时延误。界面方向文案不清时另核对运营方方向，不能猜。

无结果列表时先辨认交互是否真正提交：本机ExploreShanghai只填入站名没有候选，补browser_type的submit=true后才出现具名站点，再选中；不要把输入框有字误当路线查询成功。

莱西另一路径：从两地点查询改搜“莱西 月湖公园 王府井 11路”，观海新闻 `https://m.guanhai.com.cn/p/408540.html` 的2025-09-08开通报道有山文学院→万达广场站序、王府井站及当时7:00—17:00信息。搜索百科却给另一组端点和2元票价，不能把这份票价拼接到新报道线路。报道提及覆盖月湖公园，但站表无同名站，且不是当日时刻表：仅取得交通线索，未核公园入口到上车站步行、影院距离或2026年票价。下一步仅补相同线路/方向的当前运营信息，不能拿“线路18公里”充当两地点距离。

仅有文本工具时，可用已核实站点链给静态指引，动态路况/完整耗时留未验证。查得到一个可用方案不等于最短或唯一方案；缺用户起点仍需询问，不使用服务器默认定位。

## 收尾

输出起终点、方向、交通方式、适用时间、来源与缺口。直线距离、路程、预计时间分开；多方案只比较相同出发条件。证据不足以满足到达期限就明确说明，不用精确数字补齐。不自动开启定位、保存地点、叫车或发送位置。
