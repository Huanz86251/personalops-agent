# 跨领域证据调查

## 查询与判断

把任务拆成待证实事实，标出主体、日期、范围及缺失字段。每次检索应解决一个缺口。结果偏题先改词或限定域名；相关但覆盖不足才翻页。保留中文实体和英文专有名词，不把相同查询反复翻译当成新调查。

优先对该事实负有直接发布责任的来源。转载追原文，经验内容核对作者、日期和证据；营销、拼接和无出处页面降级，不能按域名一律判真伪。搜索摘要用于定位，关键结论核对原页。

## 按页面状态换路

有 fetch_webpage 时先读静态正文小段；相关内容未读完才沿 next_index 继续，每段会重新抓取。只有导航、图片编码或模板时找正文直链或转浏览器。浏览器按观察到的控件操作，等待目标状态；HTTP 成功与下载成功均不代表内容已验证。

普通事实查询遇到登录墙，优先同一发布者的公开材料或可信替代源。仅 JS 未渲染可正常用浏览器；明确验证码/403/429 不反复刷新或绕过。用户指定的账户任务按既有授权流程处理。工具占用与网站封禁分别记录。

先看“目标字段是否存在”，不是只看字数或HTTP成功。壳页换渲染方式，连接故障换发布入口，过期内容找同实体新公告；每次改变一个能补证的条件。正文有登录按钮不等于必须登录。长导航后可能真有正文：有匹配标题/直链且返回还有内容时可定位后段；整页仅图片编码则不机械翻完。

实测：ZOL参数页前12,000字符多为导航，后段才有M650-M参数和参考价；浏览器 browser_find“参考报价”直接返回带型号的短片段。提交时引用这一真实定位调用，不只交整页开头或自己的摘抄。Reporter不继承完整网页历史，长结果被截断后可能看不到核心字段。

## 冲突与收敛

冲突先核对版本、地区、单位及发布/事件时间，再判断是否确实矛盾。同稿转载不算多份独立证据。保留“结论—URL—定位—范围—缺口”，不抄整页。足以覆盖当前标准即结束；原文不可读时明确缺证，不能由摘要补细节。
