# 场馆到访

## 查询入口

明确城市、馆区/分馆、参观日期和人群条件，搜索“场馆全名 馆区 开放时间/参观/交通”，先找运营方具体正文，不先请求地图主页。地址和附近车站已足够回答时不再加载路线方法。

第一次搜索可一次并发覆盖运营方到访页、目标日期临时公告、交通入口三个互补字段，例如：`web_search(query="<场馆全名> <馆区> 开放时间 参观", alternative_queries=["<场馆全名> <日期> 临时公告", "<场馆全名> 入口 交通"])`。用户只问其中一个字段时删掉无关分支；任一运营方正文已经覆盖开放、门票和入口等用户所需字段，就直接回答，不为补齐整套参观攻略继续搜索。

本机2026-09-06抽样：上海博物馆官网 visit-east 桌面/移动页可读开放、入口、地铁出口与公交；故宫 dpm.org.cn/Visit.html 有导览与临时公告。仅为已测试入口例子，不保证永久可达。

过窄查询可减词：`site:shanghaimuseum.net 东馆 交通 地铁` 本次无结果，改成 `site:shanghaimuseum.net "东馆" "开放时间"` 找到含交通的到访页；不能因单次无结果就断言无资料。

## 按字段核验

开门、停止入馆、闭馆分别记录；核对周闭馆、节假日、临时停展及适用日期。某展厅关闭不等于全馆关闭。门票区分常设/特展、人群优惠与预约要求；公开票价不证明目标日期有余票。

门址、散客/团队/无障碍入口可能不同；附近车站指引不证明出口实时开放，更不能推出用户全程耗时。需要起终点行程时才组合 web-map-routes。

## 回退与收尾

正文不可读时找运营方具名公告或可核对转载；疑似解码错误先换同一运营方的公开直链、移动页或下载文件，普通参观查询不补选浏览器。只有用户原始请求明确要求页面预约/筛选等操作且首次路由已挂载 `BROWSER_AUTOMATION`，才使用页面控件。文旅介绍只补其支持的基础信息：北京旅游网电影博物馆页含2024年暑期安排，下一次查询应增加目标日期和“开放公告”，而不是重复读该旧介绍。未找到当前规则就保留此字段缺口。

输出目标日期适用的规则、来源与未确认条件；只读首段不声称查完全部公告。无法核实余票/临时安排就说明，不擅自登录、预约、购票或改变用户日期。
