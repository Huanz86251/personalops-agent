# 影院与场次

## 固定身份

明确城市、影院分店、影片、观影日期/时段和必要版本条件（语言、2D/3D、影厅）。相对时间按任务时区落到日期，不能拿历史排片或同名影院填空。只找影院名单时不强制收集全部影片和余座。

搜索“城市 影院分店 影片 日期 排片”；无结果可放宽非硬条件，不偷偷更换用户必须的日期/地点。优先已发现的院线/影院具名影讯，页面叫“近期影讯”不证明含今天的数据。

## 动态票务边界

猫眼文本仅返回“猫眼电影”时，不继续分页读壳：若需要目标影院场次，找该影院/院线公开影讯或用真实浏览器正常渲染；不能拿附近推荐店的价格填空。服务器默认城市不是用户位置，换影院必须有用户范围依据。

同影院实测（2026-09-06）：`https://co.maoyan.com/shows/40995` 文本仅4字，项目浏览器却正常转到 `www.maoyan.com/cinema/40995`，确认横店电影城（莱西王府井店），选“今天9月6”读到《八仙！》国语2D的16:05、17:15、18:40、21:15场次及影厅。先保留这些已成功字段，不能继续说“猫眼拿不到”。售价单元格返回私有区字符而非数字，应单列“票价文字不可读”：只有实际注册的截图/视觉读取能力能核对时才使用，否则改找同院同场公开报价或留缺口，不猜字形、不把别院票价补进来。当前项目浏览器白名单没有截图工具；不能在Skill里虚构该能力。未选座或购票，不声称已核余座。

实测可用分支：电影博物馆官方近期影讯文本曾乱码，改用项目浏览器MCP打开同一页，正常读到日期分组（9月6日至10日）、影片/影厅/时间/价格表。策略是“同页文字解码/嵌入内容缺失→浏览器渲染→定位目标日期表”，不是把官网标为不可用。页面还有其他日期和公告，不能只凭页头今天日期给所有场次贴今日标签；这也不证明莱西或其他影院有同样入口。

无浏览器或遭登录/验证码/强制App阻断时换同影院具名日期影讯，仍缺则保留精确缺口，不绕过限制。匿名公开排片可读不意味着余座或优惠结算也可读。

## 核验与输出

每条场次绑定“影院分店—日期—影片/版本—开始时间”。价格还需座位/影厅/优惠条件；列表起价不等于指定场次总价，有排片不等于有余座。特别检查“暂无该影院影片信息”“附近推荐”，不得把别店票价归给目标影院。

分开报告已找到影院、已核实场次、未确认余座/价格，附来源与查询时点。只询价不选座锁位、不购票、不登录或联系影院，不凑场次补全答案。
