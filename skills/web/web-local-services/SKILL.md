# 门店与本地活动

## 定位需求

提取城市/商圈、店名/分店、日期、预算和用户关注字段。“附近”需要已给定或授权的位置，不猜用户城市。普通门店地址可直接核对；只在需要起终点路线/距离/耗时时才组合 web-map-routes。

用“城市 店名 分店 目标字段”找实体，按证据缺口调整查询。结果偏题先核对同名店或减少非核心词，不机械翻页。查询里的“官方”二字不能证明搜索结果是官方发布。

## 证据分工

营业规则、服务项目和活动日期优先运营者正文；体验和设施可参考有时间、分店身份的用户记录，评分/旧排队经历不代表现在的服务承诺。价格注明人均、套餐或单品，不能混为消费总额。

分店混淆时把商圈/街道加入查询，找品牌门店目录中的具名条目，不继续堆探店文章。实测：陶陶居总店查询曾混入别店、知乎正文403；改搜“陶陶居 总店 第十甫路 官网 营业”，官网门店页读到“广州第十甫路总店”、第十甫路20号一楼及电话。地址身份缺口已补齐，营业时间未展示就继续只找总店当日安排，不套用其他分店时间。

活动平台/本地宝用于发现具名活动，再核对实际活动日和主办者；文章年份正确也可能是已结束的单日安排。正文后的公众号推广不是必须关注才能阅读。

## 失败与报告

空壳、乱码、明确拒绝和连接错误分别报告，换对应公开来源，不绕访问限制。无法核实营业、排队或余位就保留缺口，不靠摘要补答案。

输出少量符合用户条件的候选，附分店、日期、价格口径、来源与未知项。查询不授权预约、购买、登录、联系商家或发送消息；证据已覆盖请求即停止。
