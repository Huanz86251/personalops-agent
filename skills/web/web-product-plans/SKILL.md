# 产品规格与有条件价格

这里只处理厂商产品信息与服务计费方案；具体店铺现价、SKU及优惠核验用 web-shop-prices。用户同时要求技术选型和指定商家比价时才组合，不因两者都有“价格”就同时加载。

先列出影响选择的硬条件：型号/版本、地区、用途、预算、用量、购买或订阅周期。查询用“产品精确名 型号/套餐 地区 pricing/价格 目标字段”，不要把不同代际或基础版/专业版混为同一产品。

规格先查厂商文档和支持页；价格先查对应地区官方价格页，再按任务需要核对实际销售页面。性能和体验查有方法、样本及日期的独立测试，社区内容可补使用问题，不能把营销形容词当测试数据。

逐项核对货币、含税/运费、月付/年付、试用/续费、人数/用量上限、优惠条件及时间。“起价”与特定配置实际总价分开；用量未知时给条件性比较，不虚构精确最便宜方案。

页面需要选择地区或型号时，用浏览器观察实际控件并确认当前选择。登录才能看的专属折扣、购物车或强制 App 页面，可改查公开标价并说明差异；不为询价注册、下单或改变账户。搜索摘要中的旧促销只作定位。

地区错配就用“型号 目标地区 规格/资费条款”重查具名页，不沿通用购买首页猜产品。实测小米15香港规格页可读但不支持大陆报价；中国移动某业务页TLS失败也不等于必须登录，换源仍须绑定同省同套餐。

规格与购买页可分工：M650商品直链只读到京东壳时，换罗技 zh-cn 同型号页，继续读 next_index 后获得SmartWheel与连接方式说明；比价页则提供参考价线索。分别用于功能与报价，不能因两页同型号就推出当前有货或大陆成交价。

输出围绕用户维度的小表，附价格日期与来源，缺失项写未确认。可信资料足够时结束；同一营销稿多个转载不算独立性能证据。
