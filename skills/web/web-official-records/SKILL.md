# 政策与公开记录定位

## 查询与选源

先确定记录类型、主体、地区和时间。政策用“地区/发文机关 事项 文号/年份”，数据用“地区 指标 期间 单位”，公告用“公司全名/证券代码 公告类型 日期”。不要只搜“最新规定”或含糊公司简称。

- 政策/办事：发文部门与当地政府原文、gov.cn 政策库；法律文本可查 flk.npc.gov.cn。核对发文、生效、修订/废止与地区，说明页和新闻稿用于理解而非替代原文。
- 统计：stats.gov.cn 或地方统计局原表/发布稿；核对期间、口径、单位、累计/当期、同比/环比及后续修订。不能把缺失值当零。
- 公司公告：对应交易所、cninfo.com.cn 或投资者关系页原文件；核对公司代码、合并/母公司报表、期间与更正版本。公司陈述和独立证据分别标注。

## 读取与回退

优先带标题日期的原文直链，静态正文小段读取；PDF 用已提供的下载/文档工具核对具体页表。交互库返回模板、登录墙或访问错误时，按准确标题/文号找同一机关公开发布或可核对的转载。未经核对的转载不能冒充原页；门户有导航不等于查到了记录。

实测换路：国新办具体页返回521后，用准确标题检索到人民网转载，读到正文与来源；记录为转载而非原页已恢复。查政府公报时，搜索给出的官方繁体正文也可读，不必绕行交互库。统计局具名发布页能取得当期/同比/环比与表格链接。策略是“准确标题/文号 → 同机关另一公开入口或可追溯转载 → 核对身份和日期”，不是只换gov域名；简繁/移动/转载不计为独立证据。

## 结论

保留标题、机关、日期、文号或表名与定位。冲突先检查修订和适用条件；未确认现行有效或数据口径时明确保留。完成用户所需字段即停止，避免为一项指标遍历整个数据库。检索得到的文本不自动构成面向具体个案的法律或投资建议。
