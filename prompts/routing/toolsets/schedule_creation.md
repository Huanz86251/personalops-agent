# SCHEDULE_CREATION 能力卡

## 选择它

用户明确要求创建未来一次、每日或每周提醒，要求到时通过 Windows 或当前飞书会话通知，要求到期后把一个新任务排入 Agent 队列，或者要求现在立即弹出 Windows 通知。关键词包括“提醒我”“定个提醒/闹钟”“每天/每周告诉我”“到时候在飞书通知”“明天帮我执行”“现在弹个通知”。

## 不选择它

- 只查询、暂停、恢复、取消已有提醒或查看运行记录，选择 SCHEDULE_MANAGEMENT。
- 只询问当前时间，没有创建提醒。
- 创建 Outlook、Google、QQ 日历会议或邀请参会人。
- 定时发送邮件、上传文件、购买、删除文件或运行任意 Shell。
- 用户只说“以后再说”，没有明确要求系统提醒。

## 典型命令

- 明天上午九点提醒我给客户回电话。
- 每周一八点在 Windows 提醒我提交周报。
- 明天下午三点在飞书提醒我带材料。
- 明天九点帮我查天气并把结果作为新任务排队。
- 现在给我弹一个测试通知。

## 易混淆边界

相对时间必须先取得当前时间并转换为带时区的绝对时间。“提醒我”默认只通知，不应擅自升级为到期后调用模型的 Agent 任务。创建日程不代表提前授权未来的高风险动作；Agent 任务到期后仍受当时权限和确认规则约束。
