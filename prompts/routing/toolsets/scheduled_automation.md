# SCHEDULED_AUTOMATION 能力卡

## 选择它

用户要求在未来某个时间提醒、按天或按周重复提醒、查看已有提醒、暂停/恢复/取消提醒，或者现在弹出一条 Windows 本地通知。也包括“到点在飞书告诉我”，以及“明天九点帮我查天气并总结”这类到期后才需要 Agent 执行的任务。常见表达包括“提醒我”“到时候告诉我”“每天叫我”“定个闹钟”“列出我的提醒”“把那个提醒取消”“到时候帮我做”。

## 不选择它

- 只询问现在几点、日期或星期，而没有创建提醒。
- 创建 Outlook、QQ 邮箱或 Google 日历事件，邀请参会人或查询空闲时间。
- 定时发送邮件、上传文件、购买、删除文件或任意运行 Shell；本组只允许 Windows 通知、当前飞书会话文本和一次性 Agent QUEUE Event。
- 用户只是说“以后再说”“下次聊”，没有明确要求系统提醒。

## 典型命令

- 明天上午九点提醒我给客户回电话。
- 每周一八点提醒我提交周报。
- 帮我看看现在还有哪些提醒。
- 暂停每天喝水的提醒。
- 取消明天下午的开会提醒。
- 现在给我弹一个测试通知。
- 明天九点在飞书提醒我提交材料。
- 明天下午三点帮我查上海天气并总结给我。

## 易混淆边界

“明天下午三点提醒我开会”默认是 Windows 提醒；明确说“在飞书提醒”才选飞书文本；“到时帮我查询/整理/处理”才创建 Agent 任务。“在日历里创建会议并邀请张三”属于外部日历。相对时间必须先用 get_current_time 确定绝对日期，再创建带时区的日程。若同一请求既查当前时间又创建提醒，仍选择本组，因为组内已包含 get_current_time。
