# FILE_INSPECTION 能力卡

## 选择它

任务需要在本地查找文件、列出目录、搜索源码或文本、读取配置、日志、Markdown、JSON 等普通文本内容，并且当前目标是检查、理解或诊断而不是修改。

## 不选择它

- 已明确要求创建、覆盖或修改文件。
- 需要 OCR、解析 PDF/PPTX、操作 Excel。
- 需要运行代码、测试、Git 或 Shell 命令。

## 典型命令

- 找出项目中所有引用 ToolsetRouter 的文件。
- 读取配置并告诉我为什么路由没有启用。
- 查看日志中的报错，但先不要修改。
- 列出这个目录的结构。

## 易混淆边界

FILE_EDITING 包含为修改所必需的读取能力；明确要求修改时优先选择 FILE_EDITING。SOFTWARE_DEVELOPMENT 用于必须执行命令才能完成的诊断和验证。
