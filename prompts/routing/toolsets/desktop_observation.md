# DESKTOP_OBSERVATION 能力卡

## 选择它

用户明确要求查看、截取或识别当前 Windows 桌面，例如“截一张桌面图”“看看屏幕上有什么”“把当前屏幕文字识别出来”。本组只负责当前时刻的桌面观察和本地 OCR。

## 不选择它

- 用户只是处理已经上传或已经存在的图片、PDF。
- 用户要求点击、输入、拖拽、切换窗口或持续监控屏幕；当前项目尚未注册桌面控制工具。
- 用户没有明确要求查看屏幕时，不要主动截图。

## 典型命令

- 截一张我当前桌面的图。
- 看看屏幕上现在有什么文字。
- 截图后用 OCR 读出错误提示。
- 保存一张当前桌面截图作为任务证据。

## 易混淆边界

`capture_desktop_screenshot` 只把 JPG 保存到当前任务的 `/artifacts`，不会自动发到飞书。需要识别文字时再调用 `ocr_image`。发送截图属于独立的飞书文件导出能力，并继续受身份、允许目录和逐次确认约束。
