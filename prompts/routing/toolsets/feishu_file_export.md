# FEISHU_FILE_EXPORT 能力卡

## 选择它

用户明确要求把已经存在于本机的文件或目录发送、回传、上传到当前飞书会话，例如发送报告、压缩并回传目录、把生成结果传给我。

## 不选择它

- 只是读取、总结、修改或生成文件，但没有要求发回飞书。
- 发送电子邮件、上传到网页、网盘或其他聊天平台。
- 用户尚未给出发送意图时，不因任务可能产出文件而提前选择。

## 典型命令

- 把 D 盘这个 PDF 发到当前飞书会话。
- 将刚生成的结果目录打包回传给我。
- 把报告传到飞书。

## 易混淆边界

生成或修改文件属于 FILE_EDITING、LOCAL_DOCUMENTS 或 SOFTWARE_DEVELOPMENT；只有“把本地成品交付到当前飞书”才属于本组。选择本组不代表跳过宿主的独立确认、白名单和大小限制。
