# FEISHU_FILE_EXPORT 能力卡

## 选择它

用户明确要求把本机文件、Worker下载文件、已审核handoff文件或当前工作区成品发送、回传、上传到当前飞书会话，例如发送报告、压缩并回传目录、把生成结果传给我。

## 不选择它

- 只是读取、总结、修改或生成文件，但没有要求发回飞书。
- 发送电子邮件、上传到网页、网盘或其他聊天平台。
- 用户尚未给出发送意图时，不因任务可能产出文件而提前选择。

## 典型命令

- 把 D 盘这个 PDF 发到当前飞书会话。
- 将刚生成的结果目录打包回传给我。
- 把报告传到飞书。

## 易混淆边界

生成或修改文件属于 FILE_EDITING、DOCUMENT_CONVERSION、SPREADSHEET_WORK 或 SOFTWARE_DEVELOPMENT；只有“把成品交付到当前飞书”才属于本组。每次外发都经过独立Judge；用户原始请求已经明确要求发送时可直接放行，存疑才暂停询问用户。选择本组不代表跳过宿主身份、会话、文件完整性和大小限制；大小上限取本机配置与飞书平台 30 MB 上限中较小者。超限时先询问用户是否允许拆分，不得自行拆分后重试。
