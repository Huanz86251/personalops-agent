# MOVIE 能力卡

## 选择它

用户询问当地影院、某天或今晚的电影排片和逐场票价。简称电影或影院、按爱情/恐怖等类型找有场次的影片，也属于这里。

## 不选择它

- 普通场馆参观、地图导航、新闻搜索，或与电影无关的网页研究。
- 订票、锁座、付款、查询个人订单或余座和上座率。

## 典型命令

- 莱西明天有哪些电影院和爱情片？
- 王府井那家影院明天几点放《奥德赛》，各场多少钱？

## 边界

排片工具是本组必需能力。本组不包含 Playwright；排片工具或 Web Search 失败不是补选浏览器的理由。只有用户原始请求明确要求页面点击、筛选或登录操作时，首次路由才可另选 BROWSER_AUTOMATION。
