# WEB_RESEARCH 能力卡

## 选择它

任务需要搜索或核对互联网中的最新、公开、可能变化的信息，读取公开网页，比较多个在线来源，或提供带来源的研究结论。

## 不选择它

- 需要点击按钮、登录、填写表单、下单、发送消息或完成网页工作流。
- 只处理本地已有文件。
- 用户只问稳定常识且不要求查证、最新信息或来源。

## 典型命令

- 查一下今天英伟达的最新新闻并核对来源。
- 比较这三款产品现在的价格和规格。
- 找到官方文档并解释这个 API 的当前用法。
- 调研工业界如何做工具路由。

## 易混淆边界

WEB_RESEARCH 负责“找信息、读内容、核对来源”；BROWSER_AUTOMATION 负责“在页面上执行动作”。研究后还需要网页操作时可以同时选择两组。
