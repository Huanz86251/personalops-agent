# WEB_RESEARCH 能力卡

## 选择它

任务需要搜索或核对互联网中的最新、公开、可能变化的信息，读取公开网页或微信公众号文章，比较多个在线来源，或提供带来源的研究结论。

## 不选择它

- 需要点击按钮、登录、填写表单、下单、发送消息或完成网页工作流。
- 只处理本地已有文件。
- 用户只问稳定常识且不要求查证、最新信息或来源。

## 典型命令

- 查一下今天英伟达的最新新闻并核对来源。
- 比较这三款产品现在的价格和规格。
- 找到官方文档并解释这个 API 的当前用法。
- 调研工业界如何做工具路由。
- 搜索微信公众号里今天与莱西相关的热门内容，并给用户整理要点。
- 同时从本地政务、民生事件和行业观察三个互补角度搜索公众号文章。

## 易混淆边界

WEB_RESEARCH 负责“找信息、读公开静态内容、核对来源、取得直接下载链接”；BROWSER_AUTOMATION 只负责用户明确要求的页面动作。普通调研、餐厅/电影/商品推荐、搜索结果质量不理想或遇到登录墙时，仍只选本组，不把浏览器当作潜在兜底。只有用户原始请求同时明确包含查资料和页面操作时，才在首次路由中同时选择两组。
