# FILE_EDITING 能力卡

## 选择它

任务明确要求创建、覆盖或精确修改本地文本文件，例如源码、配置、Markdown、JSON、YAML、提示词或脚本；同时允许为修改定位和回读相关内容。

## 不选择它

- 用户只要求检查、解释、评审或诊断，未授权修改。
- 需要执行代码、测试、构建、Git 或安装依赖。
- 主要目标是 PDF/PPTX/OCR/Excel 等文档处理。

## 典型命令

- 修改配置文件中的模型名称并回读确认。
- 新建一份路由能力卡。
- 精确替换这段提示词，不要动其他内容。
- 更新 README 的使用说明。

## 易混淆边界

若修改属于完整的软件实现且必须运行测试验证，选择 SOFTWARE_DEVELOPMENT，必要时也可选择本组。只读任务属于 FILE_INSPECTION。
