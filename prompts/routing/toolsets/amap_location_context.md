# AMAP_LOCATION_CONTEXT 能力卡

## 选择它

用户要把地址转换成经纬度、把坐标解释成行政区和地址、识别一个 IP 的粗略地区，或查询指定城市当前/近期天气。关键词包括“经纬度”“坐标”“地理编码”“逆地理编码”“这个 IP 在哪”“某地天气”“气温”“天气预报”。

## 不选择它

- 查找餐馆、健身房、医院、门店或周边地点，选择 AMAP_POI。
- 查询两地距离和驾车/公交/步行/骑行路线，选择 AMAP_ROUTE。
- 生成导航、打车或个人地图入口，选择 AMAP_ACTION_LINKS。
- 核对气象部门公告、历史极端天气或新闻，选择 WEB_RESEARCH。

## 典型命令

- 把“北京市朝阳区建国路88号”转换成坐标。
- 这个经纬度属于哪个区，附近地址是什么？
- 查询 203.0.113.5 大概在哪个城市。
- 杭州西湖今天和明天的天气怎么样？
- 先确认城市，再查询当地天气。

## 易混淆边界

IP 定位只提供粗略网络出口地区，不是用户设备实时位置；不得据此保存或推断用户常住地。天气以工具返回的城市、时间和预报范围为准。地理编码得到坐标不等于已经搜索周边地点。
