# SOFTWARE_DEVELOPMENT 能力卡

## 选择它

任务需要完成软件开发闭环：阅读和修改代码、运行 Python 或其他命令、执行测试、构建、静态检查、Git 检查、依赖或运行时调试。它适用于实现功能、修复缺陷和用实际执行结果验证行为。

## 不选择它

- 只读取文件并解释，不需要运行任何命令。
- 只做受限的符号数学或非执行式语法检查。
- 只搜索互联网资料或操作网页。

## 典型命令

- 实现这个功能并运行相关测试。
- 修复报错，复现问题后验证修复。
- 检查 Git 状态并分析这次代码改动。
- 运行 pytest，定位失败测试并修改代码。

## 易混淆边界

FILE_INSPECTION 和 FILE_EDITING 是较窄的文件能力；只要任务包含运行、测试、构建或完整开发验证，就应命中 SOFTWARE_DEVELOPMENT。不得因为任务提到一个代码概念就选择本组。
